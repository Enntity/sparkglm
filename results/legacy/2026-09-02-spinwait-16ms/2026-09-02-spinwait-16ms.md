# Spinwait 16 ms acceptance — 2026-09-02

## Verdict

Keep `GLM53_SPINWAIT_MS=16` as the opinionated TP2 default. It improved the
primary delivered-throughput metric on the real four-stream 33K staggered
workload and had already won the frozen decode sweep.

## Byte-equivalent C4 gate

Both runs used image digest
`sha256:107d899515629f168fdd5f7bac3e967bc3d0fe768124bafd9322c7a3a8c4adc4`,
vLLM `0.1.dev47+g6a49e49e7`, mixed scheduling, MNBT 7,168, DFlash2 K7/TP2,
FP8 target KV, FP16 sparse-indexer scores, four requests arriving at
0/1/2/3 seconds, about 33K prompt tokens each, and exactly 400 output tokens
per request. The candidate changed only the shared-memory reader spin window.
A restart between runs cleared prefix cache state; both captures used the same
prompt salt and reported prompt-token counts 32,999 / 33,002 / 33,002 / 33,001.
